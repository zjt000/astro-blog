# 安装oh-my-zsh以及插件

1. 安装oh-my-zsh

```bash
sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
```

2. 安装插件

```bash
git clone https://github.com/zsh-users/zsh-completions.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-completions

git clone https://github.com/zsh-users/zsh-autosuggestions ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions

git clone https://github.com/zsh-users/zsh-syntax-highlighting.git ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting
```

3. 配置

```bash
vim ~/.zshrc
```

>linux
>```bash
> git clone https://github.com/lgulliver/lcars-zsh-theme.git && cp lcars-zsh-theme/lcars.zsh-theme ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/themes/ && rm -r lcars-zsh-theme
>```
>
>ZSH_THEME="lcars"

> macOS
> ```bash
> brew install starship
> ```
>
> ZSH_THEME=""
>
> eval "$(starship init zsh)"

添加以下内容:
>内置插件按需添加
```bash
plugins=(
    git
    zsh-completions
    zsh-autosuggestions
    zsh-syntax-highlighting
)
```

4. 重启zsh
```bash
source ~/.zshrc
```

5. 升级oh-my-zsh
```bash
# 更新oh-my-zsh(内置插件会一起更新)
omz update
```
6. 升级第三方插件
```bash
git clone https://github.com/lgulliver/lcars-zsh-theme.git && cp lcars-zsh-theme/lcars.zsh-theme ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/themes/ && rm -r lcars-zsh-theme

cd ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-completions && git pull

cd ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-autosuggestions && git pull

cd ${ZSH_CUSTOM:-~/.oh-my-zsh/custom}/plugins/zsh-syntax-highlighting && git pull
```

7. 卸载oh-my-zsh
```bash
uninstall_oh_my_zsh
```
